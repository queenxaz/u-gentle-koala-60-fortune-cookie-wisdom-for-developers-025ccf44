Fortune-cookie wisdom for a developer, from a tired senior engineer: the bug is never where you think.

## The entry

**Your code will compile on the first try today — the bug you fear is in the meeting, not the merge.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
